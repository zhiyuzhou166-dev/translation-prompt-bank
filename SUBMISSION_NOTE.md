## Ready-to-paste submission note (English)

The web app I built with AI is **TransPrompt Bank**, a bilingual translation prompt library, deployed and publicly accessible without login:

Live link: https://zhiyuzhou166-dev.github.io/translation-prompt-bank/

The app organizes the translation workflow into three stages — pre-production, production and post-production — with 27 bilingual prompt groups (54 prompts in Chinese and English) plus 2 Meta Prompts. It offers stage and scenario filters, full-text search, independent interface/prompt language switches, placeholder substitution and one-click copy. It is built with vanilla HTML, CSS and JavaScript (no dependencies, no build step) and hosted on GitHub Pages. The bilingual README and the three-round AI collaboration log are in the repository.

Screenshots are in the repository's screenshots folder: home.png shows the homepage, and features.png shows the prompt explorer with filtering and copying.

For user feedback: the project owner Zhou Zhiyu asked for a deployable vibe-coding version with a bilingual README, so I made the site build-free for GitHub Pages and provided step-by-step deployment commands. A friend who is not a translation major tried the site for two days and said verbatim: "For students who are not translation majors, it is quick to get started with translation tasks, and you can quickly find a suitable prompt. Translation quality is better when using these prompts." In response, I added three clickable stage cards, refined full-text search and the scenario dropdown, added placeholder filling with one-click copy, wrote a 3-step quick-start guide, and preserved the original model names and version numbers for further prompt iteration.

Repository: https://github.com/zhiyuzhou166-dev/translation-prompt-bank
